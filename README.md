# দৈনিক আমাদের কথা (Doinik Amader Kotha)
*সবার সংযোগ, সবার সুখ-দুঃখ আর কাজের খবর*

"দৈনিক আমাদের কথা" একটি আধুনিক ও স্বয়ংক্রিয় অনলাইন নিউজপেপার পোর্টাল। এটি নিয়মিত দেশের বিভিন্ন প্রান্ত থেকে গুরুত্বপূর্ণ ও ট্রেন্ডিং খবর সংগ্রহ করে অত্যন্ত সুন্দর ও পরিপাটি বাংলা ভাষায় প্রকাশ করে।

## টেকনোলজি স্ট্যাক:
* **Frontend:** HTML5, Tailwind CSS, JavaScript
* **Automation:** GitHub Actions (Scheduled Cron Job)
* **Content Engine:** Google API Integration
* **Hosting:** GitHub Pages
